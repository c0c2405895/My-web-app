# AI Wardrobe

天気とワードローブの登録情報をもとに、今日のコーディネートを提案する Flask アプリです。
服の画像を登録し、提案への評価を蓄積することで、好みの色を次回の提案に反映します。

## ポートフォリオ概要

- **課題**: 毎朝の服選びに時間がかかり、所有している服も活用しきれない
- **解決策**: 現在地の天気・気温と手持ちの服を組み合わせ、理由付きでコーディネートを提案
- **工夫点**:
  - Open-Meteo API が利用できない場合も、フォールバック値でデモを継続
  - 画像のファイル名と入力内容から、カテゴリ・素材・暖かさをローカルで推定
  - 「好き／好みではない」の評価を次回の色選択に反映
  - モバイル表示、画像アップロード、プロフィール設定、通知設定に対応

## 技術構成

- Python / Flask
- HTML / CSS / JavaScript
- Open-Meteo Geocoding API・Forecast API
- JSON ファイルによるローカル永続化

## ローカルで実行

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:SECRET_KEY = "local-development-secret"
python app.py
```

ブラウザで <http://127.0.0.1:5000> を開いてください。

ログイン画面はポートフォリオ用のデモ認証です。任意の識別子とパスワードを入力すると利用できます。
本番運用では、ユーザー情報をデータベースに保存し、パスワードハッシュ・メール認証・CSRF対策を追加します。

## データと画像

実行時データは `app/wardrobe.json` と `uploads/` に保存されます。これらは `.gitignore` 対象です。
初回起動時にはサンプルデータが生成されます。

## 環境変数

| 変数 | 用途 | 既定値 |
| --- | --- | --- |
| `SECRET_KEY` | Flask セッション署名キー | 起動ごとにランダム生成 |
| `PORT` | 待ち受けポート | `5000` |
| `FLASK_DEBUG` | 開発デバッグモード（`1` のとき有効） | 無効 |
| `COOKIE_SECURE` | HTTPS 接続時の Secure Cookie（`1` のとき有効） | 無効 |

## GitHub に公開する前の確認

1. `SECRET_KEY`、個人情報、実行時画像をコミットしない
2. `FLASK_DEBUG` を有効にしたまま公開しない
3. README の起動手順をクリーンな環境で確認する
4. Open-Meteo API が利用できない状態でも画面が表示されることを確認する
